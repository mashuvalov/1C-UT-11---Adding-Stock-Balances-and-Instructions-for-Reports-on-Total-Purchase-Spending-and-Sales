# На какую сумму организация закупила товары

**Отчет — «Динамика закупок организаций», показатель «Сумма закупок».** Он показывает поступления товаров в стоимостной оценке учета.

Отчет показывает, на какую сумму закуплены товары за выбранный период, даже если организация еще не оплатила их поставщику. Предоплата и оформленный заказ без закупки товара в эту сумму не входят.

## 1. Как найти отчет

1. Открыть **Закупки → Отчеты по закупкам**.
2. В поиске панели отчетов ввести **Динамика закупок организаций** и открыть найденный вариант.
3. Если виден только вариант **Динамика закупок предприятия**, открыть его и нажать **Варианты отчета**. Выбрать **Динамика закупок организаций**.
4. Если нужного варианта нет на панели, нажать **Настройки / F2**, найти вариант и включить его видимость. Также можно перейти в **Все отчеты** и найти его там.

Вариант «по организациям» нужен для конкретного юридического лица. Вариант «по предприятию» предназначен для анализа предприятия в целом и использует другую стоимостную оценку.

## 2. Как настроить

Нажать **Настройки → Вид → Расширенный**. Часть параметров уже может находиться в шапке отчета. Условия отбора расположены на вкладке **Фильтры**; в зависимости от интерфейса она также может называться «Отборы».

| Настройка | Что установить |
|---|---|
| Период | Нужные даты начала и окончания, например 01.08.2026–31.08.2026 |
| Организация | Включить отбор и выбрать нужную организацию. При условии «В списке» оставить в списке только ее |
| Данные по себестоимости | **В валюте регл. учета** |
| Номенклатура → Тип номенклатуры | **Равно → Товар**, чтобы отделить товары от услуг и тары |
| Поставщик | Оставить отбор выключенным для суммы по всем поставщикам |
| Номенклатура, склад, сегмент | Убрать лишние ограничения, если нужна сумма по всем товарам организации |

Поле **Организация** в дереве доступных полей находится в группе **Структура предприятия**. Поле **Номенклатура** — в группе **Аналитика номенклатуры**; раскрыть его реквизиты для выбора типа номенклатуры.

**Рубли:** режим «В валюте регл. учета» использует валюту регламентированного учета выбранной организации. Проверить, что это **RUB / руб.** Режим управленческого учета сам по себе не гарантирует рублевый результат. Не следует менять валюту учета базы ради формирования отчета.

Если организация принимает чужие товары на комиссию или хранение, добавить отбор **Аналитика оборотов → Тип запасов (об) → В списке** и выбрать собственные запасы: **Собственный товар**, а при использовании соответствующих схем — также **Собственный товар в пути** и **Собственный товар по неотфактурованной поставке**. Прием чужого товара не является его покупкой. Для обычной торговли собственным товаром достаточно значения «Собственный товар».

На вкладке **Поля и сортировки** включить:

- **Сумма закупок** — основной показатель; в стандартном варианте уже включен.
- **Сумма возвратов** — чтобы отдельно видеть возвраты поставщикам; по умолчанию выключен.
- По необходимости — **Количество закупок** и **Количество возвратов**.

При выборе полей из полного дерева «Сумма закупок» соответствует **Показатели → Стоимость поступления → Приход**, а «Сумма возвратов» — **Показатели → Стоимость поступления → Расход**. В варианте отчета им назначены понятные заголовки.

Сохранить штатное ограничение **Только закупки**. Оно уже встроено в вариант. Снятие этого ограничения превращает результат в анализ более широкого круга движений запасов.

## 3. Как сформировать и прочитать результат

1. Нажать **Сформировать**.
2. Перейти к таблице под диаграммой. В стандартном варианте предусмотрены поставщики, детализация по номенклатуре и периоды по годам и месяцам.
3. Посмотреть сумму в колонке **Сумма закупок** за нужный период. Для разбивки по товарам раскрыть поставщика до номенклатуры.
4. Для результата после возвратов использовать: **закупки за вычетом возвратов = сумма закупок − сумма возвратов**.

Пример: сумма закупок — **1 000 000 руб.**, сумма возвратов — **100 000 руб.** Организация закупила на 1 000 000 руб.; после возвратов остается 900 000 руб. В итоговом результате следует уточнять, указана сумма до вычета возвратов или после него.

Не следует складывать родительскую строку поставщика с вложенными строками товаров: это повторный подсчет. Если месяцы выведены по колонкам и нет итога за весь период, можно выделить только месячные суммы в общей строке и получить их сумму встроенной кнопкой **Σ**. Для обычного списка по поставщикам можно в **Настройки → Структура** отключить диаграмму и убрать группировки по периоду из колонок таблицы.

Для проверки отдельной суммы дважды щелкнуть по ячейке и выбрать расшифровку по полю **Документ**. Если поле нужно добавить в структуру, сделать его отдельной вложенной группировкой. В отчете есть ограничение на объединение оборотных аналитик с другими полями внутри одной группировки.

## 4. Как понимать НДС и стоимость

«Сумма закупок» в этом отчете отражает **стоимость поступления** товаров. Отдельно распределенные дополнительные расходы в этот показатель не входят. Полная **Себестоимость** может быть больше за счет этих расходов.

Для варианта «Динамика закупок организаций» доступны **В валюте регл. учета** и, при соответствующей настройке базы, **В валюте упр. учета**. Переключателей «с НДС / без НДС», как у варианта по предприятию, здесь нет. Отчет предназначен для оценки стоимости без отдельно учитываемого НДС. Если по правилам учета организации НДС включается в стоимость товаров, он влияет на эту оценку. Поэтому показатель не следует автоматически приравнивать к итогу накладных с НДС.

## 5. Как сохранить и использовать регулярно

Нажать **Варианты отчета → Сохранить как** и указать название. Например, **Закупки — ООО «Пример» — руб.**.

При следующем открытии проверить период и организацию, затем нажать **Сформировать**. Вместе с результатом следует указывать период, организацию, валюту, учет НДС и вычтены ли возвраты.

Если сумма не сходится с ожиданиями, проверить проведение и даты документов, фильтры, доступ пользователя к организациям, возвраты и корректировки. Для итоговой оценки стоимости в «Динамике закупок организаций» проверить выполнение расчета себестоимости при закрытии месяца; в незакрытом периоде оценка может уточняться.
