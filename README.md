# Остатки номенклатуры по складам для УТ 11

Расширение добавляет в нижней части формы списка и формы выбора справочника **Номенклатура** панель с остатками товара, на котором стоит курсор.

Панель показывает тот же набор данных, который типовая УТ использует в подборе товаров:

- склад;
- количество «В наличии»;
- свободный остаток (колонка «Доступно»);

Расчёт выполняется штатной функцией `ПодборТоваровВызовСервера.ЦенаПродажиИОстаткиТовара`. Характеристика не задаётся, поэтому данные выводятся суммарно по характеристикам выбранной номенклатуры. В список складов передаются все не помеченные на удаление склады, доступные текущему пользователю.

## Установка из исходников

1. Откройте информационную базу УТ в Конфигураторе.
2. Откройте **Конфигурация → Расширения конфигурации**.
3. Создайте расширение с именем `АО_ОстаткиНоменклатуры`, назначением **Дополнение** и префиксом `АО_`.
4. Выберите **Конфигурация → Загрузить конфигурацию из файлов** в окне созданного расширения и укажите каталог `extension-src`.
5. Сохраните расширение и запустите предприятие.

Расширение подготовлено по исходникам **Управление торговлей 11.5.25.103**, формат XML 2.21, режим совместимости расширения `Version8_3_27`.

## Проверка

Откройте **НСИ и администрирование → НСИ → Номенклатура** и перемещайтесь по товарам. Внизу должна автоматически обновляться панель «Остатки на складах».

Затем создайте заказ клиента, перейдите на вкладку **Товары** и нажмите **Добавить**. В открывшейся форме выбора номенклатуры такая же панель должна находиться внизу и обновляться по текущей строке. Папки номенклатуры не рассчитываются.
